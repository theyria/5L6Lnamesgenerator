# 5L6Lnamesgenerator
An AI Slop generated page, to generate 5 letter or 6 letter PSN Names

✨ Features
Generation
5L or 6L usernames (5 or 6 characters)
Choose how many lines to generate (100 by default, up to 1,000,000)
Four line types, which can be combined: uppercase, digit, dash, normal
Optional first letters and last letters / digits: each letter is randomly picked in uppercase or lowercase
No duplicates option
Chunked generation with a progress bar, so the page doesn't freeze on large batches
Getting your results
Download as .txt, .csv or .json (editable file name, names.txt by default)
Copy the whole list, or click a username in the preview to copy just that one
A small sound effect plays on download 🐱
Favorites
☆ in the preview to keep a username
"Favorites" card: copy all, clear, export and import (favoris.txt file)
Customization
106 themes: green, red, blue, pink, purple, teal, orange, yellow, white, black, mixes and gradients
Sliding menu with color previews, search and a random theme
12 languages: 🇫🇷 🇬🇧 🇪🇸 🇩🇪 🇮🇹 🇯🇵 🇰🇷 🇷🇺 🇵🇱 🇺🇦 🇧🇷 🇸🇦 (Arabic is displayed right to left)
The browser language is detected automatically (English by default)
Settings, theme and favorites are remembered in the browser
Shortcuts

Buttons to check PSN username availability, create an email address (Gmail or Outlook) and create a PlayStation account.
